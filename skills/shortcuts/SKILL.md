---
name: shortcuts
description: 需要驱动 iPad 上其它 App（发消息、存相册、记事项、触发剪映等第三方动作）时使用。通过 iOS 捷径或 URL scheme 桥接，而不是直接控制。
when-to-use: 当用户希望 agent「让某个 App 做某事」、跨 App 自动化、或触发系统/第三方 App 的动作时。
---

iOS 沙盒不允许直接操纵其它 App，只能经系统通道请求它们。因此：

1. 优先用 `run_shortcut`：调用「捷径」App 里预先建好的捷径，捷径内部完成对目标 App 的操作。
   - name 传捷径名；如需传数据，用 input 传一段文本。
   - 前提：用户已在「捷径」App 里建好同名捷径。若不确定是否存在，先问用户捷径名。
2. 需要直接打开某个 App/页面时用 `open_url`，传 URL scheme（如 `things:///add?title=...`、`mailto:a@b.com`）。
3. 能力边界要如实告知用户：
   - 只能触发对方 App「已暴露」的动作；未暴露的操作（如逐帧精修）桥不过去。
   - 多数会切到前台、需要对方 App 在场，不是纯后台静默。
   - 无法定时自醒——定时需靠「捷径」App 的自动化触发器。
4. 这两个动作都会弹确认（等同写操作级别），触发前向用户说清将要做什么。
